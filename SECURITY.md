# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or privacy problem.

Email [hello@knowmapped.com](mailto:hello@knowmapped.com) with:

- a concise description of the issue;
- the affected plugin version;
- steps needed to reproduce it;
- the potential security or privacy impact; and
- any supporting screenshots or logs with personal data removed.

We will acknowledge the report and coordinate remediation and disclosure as appropriate. Never include account credentials, private map contents, API keys, or other secrets in a report.

## Supported versions

Security fixes are released in the latest published plugin version. Users should update to the most recent release and regenerate their Publii site after upgrading.
